# Sidebar — Real-Time Speaker Practice

[Open the free speaker stage](https://christopherrcardoza.github.io/sidebar-speaker-practice/)

No account required. Includes 2-, 4-, and 5-person practice, a portrait library, customizable keys, illustrated instructions, optional hand and experimental voice-tone cues, and transcript/pedal controls.

This repository contains the compiled website distribution. Authoring source is maintained privately. Browser-delivered JavaScript and assets are inspectable. Third-party software licenses are provided in THIRD_PARTY_NOTICES.txt and mediapipe/LICENSE.txt.
